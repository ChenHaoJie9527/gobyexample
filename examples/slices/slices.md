# Go Slice 教程

`slice` 是 Go 里最常用的数据结构之一。你可以把它理解成“比数组更灵活的连续元素视图”。

在日常 Go 开发里，绝大多数“可变长度的列表”需求，都会优先使用 `slice`，而不是数组。

## 1. slice 是什么

先记住一句最重要的话：

- 数组长度固定。
- `slice` 长度可变。

例如：

```go
var a [3]int
```

这里的 `a` 是数组，长度就是 `3`，类型里也包含这个 `3`。

而下面这个：

```go
s := make([]int, 3)
```

这里的 `s` 是 `slice`，长度现在是 `3`，但后面可以继续 `append` 扩展。

## 2. 为什么大家更常用 slice

因为它更适合真实开发场景：

- 可以动态追加元素
- 可以方便地截取一段数据
- 可以传给函数做列表处理
- 使用体验更接近其他语言里的动态数组

所以可以简单理解为：

- 数组更像“固定大小容器”
- `slice` 更像“日常开发默认列表”

## 3. 先看 `slices.go` 里演示了什么

当前 `examples/slices/slices.go` 这份示例，已经覆盖了 `slice` 的几个核心操作：

### 3.1 创建 slice

```go
s := make([]string, 3)
```

这表示：

- 元素类型是 `string`
- 长度是 `3`
- 初始值都是该类型的零值，这里就是 `""`

如果是 `[]int`，初始值就是 `0`。

### 3.2 读写元素

```go
s[0] = "a"
fmt.Println(s[2])
```

和数组一样，`slice` 也是通过下标访问元素。

### 3.3 获取长度

```go
len(s)
```

`len` 返回当前 `slice` 中可直接访问的元素个数。

### 3.4 追加元素

```go
s = append(s, "d")
s = append(s, "e", "f")
```

这是 `slice` 最常见的操作。

注意：`append` 可能返回一个新的 `slice`，所以一定要接收返回值。

### 3.5 复制 slice

```go
c := make([]string, len(s))
copy(c, s)
```

这表示把 `s` 中的元素复制到 `c` 中。

当你不想让两个 `slice` 互相影响时，`copy` 很有用。

### 3.6 切片操作

```go
l := s[2:5]
l = s[:5]
l = s[2:]
```

这是 Go 里很高频的写法：

- `s[2:5]` 表示取下标 `2` 到 `4`
- `s[:5]` 表示从开头取到 `4`
- `s[2:]` 表示从 `2` 取到结尾

记忆方式：

- 左闭右开
- 包含左边，不包含右边

### 3.7 字面量创建

```go
t := []string{"g", "h", "i"}
```

这是最常见、最简洁的写法之一。

### 3.8 二维 slice

```go
twoD := make([][]int, 3)
```

`slice` 可以嵌套组成二维结构，而且每一行长度可以不同，这比二维数组更灵活。

## 4. slice 的主流用法

下面这些是你以后最常写到的模式。

### 4.1 用 `make` 创建指定长度的 slice

适合你已经知道需要多少个元素，准备后续按下标赋值。

```go
nums := make([]int, 5)
nums[0] = 10
nums[1] = 20
```

### 4.2 用字面量快速初始化

适合你已经有一组初始值。

```go
names := []string{"Tom", "Jack", "Lucy"}
```

### 4.3 用 `append` 动态追加

适合边处理边收集结果。

```go
var result []int
result = append(result, 1)
result = append(result, 2, 3, 4)
```

### 4.4 用切片表达式取子区间

适合分页、窗口、截取部分数据。

```go
part := nums[1:4]
```

### 4.5 用 `range` 遍历

```go
for i, v := range nums {
    fmt.Println(i, v)
}
```

如果只要值，不关心下标：

```go
for _, v := range nums {
    fmt.Println(v)
}
```

### 4.6 用 `copy` 做“隔离副本”

```go
src := []int{1, 2, 3}
dst := make([]int, len(src))
copy(dst, src)
```

适合：

- 避免修改原数据
- 需要独立副本
- 函数内部不想影响外部传入数据

## 5. 学 slice 时最需要注意的点

这部分最重要。很多初学者不是不会写，而是会在这些地方踩坑。

### 5.1 `append` 一定要接收返回值

错误示意：

```go
append(s, "x")
```

正确写法：

```go
s = append(s, "x")
```

原因是 `append` 后，底层可能发生扩容，返回的已经不是原来的那个 `slice` 了。

### 5.2 `slice` 是“视图”，切出来的结果可能共享底层数据

例如：

```go
nums := []int{1, 2, 3, 4, 5}
part := nums[1:4]
```

这时 `part` 往往不是一份全新数据，而是和 `nums` 共享底层数组的一段视图。

所以修改 `part`，有可能影响 `nums`。

这是非常常见的坑。

如果你想要完全独立的一份数据，应该用 `copy`。

### 5.3 下标不能越界

例如：

```go
fmt.Println(nums[10])
```

如果下标超出范围，程序会直接 `panic`。

所以在访问元素前，要确认：

- 下标合法
- 切片区间合法

### 5.4 `nil slice` 和空 slice 不完全一样

例如：

```go
var a []int
b := []int{}
```

它们看起来都像“空”，而且：

- `len(a) == 0`
- `len(b) == 0`

但它们并不完全相同：

- `a == nil` 是 `true`
- `b == nil` 是 `false`

大多数日常场景下，两者都能正常 `append` 和 `range`。

初学阶段你先记住：

- 没数据时，`nil slice` 很常见
- 如果业务逻辑要区分“未初始化”和“空列表”，就要注意它们的差别

### 5.5 修改遍历中的数据要小心

例如：

```go
for i, v := range nums {
    nums[i] = v * 2
}
```

这种“按原位置修改”通常没问题。

但如果你在 `range` 循环里一边遍历一边 `append` 到同一个 `slice`，就容易让结果变得难以理解。

入门阶段建议：

- 遍历时修改当前元素，可以
- 遍历时给同一个 `slice` 扩容，尽量避免

### 5.6 `len` 和 `cap` 不是一回事

你现在先简单记住：

- `len` 是当前长度
- `cap` 是当前底层空间大概还能支撑到多大

初学者写代码时主要先关注 `len`。

但理解 `cap` 有助于你以后理解为什么 `append` 有时会扩容、有时不会。

## 6. slice 和数组的区别

这是必须真正分清楚的一点。

| 对比项 | 数组 | slice |
| --- | --- | --- |
| 长度 | 固定 | 可变 |
| 是否常用 | 较少 | 非常常用 |
| 类型是否含长度 | 是 | 否 |
| 能否 `append` | 否 | 可以 |
| 适合场景 | 固定数量数据 | 动态列表数据 |

所以在 Go 里：

- 练习语言基础时会经常看到数组
- 真正写业务时更常用 `slice`

## 7. 什么时候该优先想到 slice

如果你遇到下面这些需求，基本都应该优先想到 `slice`：

- 存一组用户 ID
- 存一批订单
- 收集过滤结果
- 读取文件每一行
- 保存接口返回的一组对象
- 构建二维数据

一句话判断：

只要你不确定元素数量是否固定，优先用 `slice`。

## 8. 学习建议：怎么读这份 `slices.go`

建议按这个顺序看：

1. 先看 `make([]string, 3)`，理解“创建一个长度为 3 的字符串 slice”
2. 再看下标赋值和读取，理解它和数组在访问方式上很像
3. 再看 `append`，这是 slice 和数组最关键的差异之一
4. 再看 `copy` 和切片表达式，理解“复制”和“截取”是两个不同动作
5. 最后看二维 `slice`，理解它的灵活性

## 9. 练习题

下面这些题目按难度递增，建议你自己先写，再运行验证。

### 练习 1：创建并打印

创建一个 `[]int` 类型的 `slice`，长度为 `5`，然后打印它。

提示：

- 使用 `make`
- 观察默认值是不是全为 `0`

### 练习 2：赋值和取值

创建一个长度为 `3` 的 `[]string`，依次赋值为 `"Go"`、`"is"`、`"fun"`，然后打印第二个元素。

提示：

- 下标从 `0` 开始
- 第二个元素的下标是 `1`

### 练习 3：用 `append` 追加元素

创建一个空的 `[]int`，依次追加 `10`、`20`、`30`，最后打印整个 `slice`。

提示：

- 注意接收 `append` 的返回值

### 练习 4：切出一段子 slice

给定：

```go
nums := []int{1, 2, 3, 4, 5, 6}
```

请分别得到：

- `[]int{2, 3, 4}`
- `[]int{1, 2, 3}`
- `[]int{4, 5, 6}`

提示：

- 用 `nums[a:b]`
- 注意右边不包含

### 练习 5：复制一份独立数据

给定：

```go
src := []int{1, 2, 3}
```

请创建一个新的 `dst`，把 `src` 的内容复制过去，然后修改 `dst[0]`，要求 `src` 不受影响。

提示：

- `dst := make([]int, len(src))`
- 再使用 `copy`

### 练习 6：遍历求和

给定一个 `[]int{3, 5, 7, 9}`，使用 `range` 遍历并求和。

提示：

- 定义一个 `sum` 变量
- 每次循环把值加进去

### 练习 7：筛选偶数

给定一个整数 `slice`，把其中所有偶数收集到一个新的 `slice` 中。

例如：

```go
nums := []int{1, 2, 3, 4, 5, 6}
```

结果应该是：

```go
[]int{2, 4, 6}
```

提示：

- 创建结果 `slice`
- 遍历原 `slice`
- 满足条件时用 `append`

### 练习 8：理解共享底层数据

给定：

```go
nums := []int{10, 20, 30, 40, 50}
part := nums[1:4]
```

请你修改 `part[0]` 的值，然后观察 `nums` 是否变化。

提示：

- 这是理解 `slice` 行为的关键题
- 修改后同时打印 `part` 和 `nums`

### 练习 9：二维 slice

创建一个二维 `slice`，第一行长度为 `1`，第二行长度为 `2`，第三行长度为 `3`，并给每个位置赋值后打印。

提示：

- 先创建外层 `[][]int`
- 再逐行 `make`

### 练习 10：自己实现一个简单删除元素逻辑

给定：

```go
nums := []int{10, 20, 30, 40, 50}
```

请删除下标为 `2` 的元素，得到：

```go
[]int{10, 20, 40, 50}
```

提示：

- 想想能不能把前半段和后半段拼起来
- 这题会帮助你更熟悉切片表达式和 `append`

## 10. 练习题参考答案

下面给出一版参考答案。写法不一定只有这一种，但思路应该类似。

### 练习 1 参考答案

```go
nums := make([]int, 5)
fmt.Println(nums)
```

说明：

- `make([]int, 5)` 创建了一个长度为 `5` 的 `[]int`
- `int` 的零值是 `0`
- 所以打印结果通常是 `[0 0 0 0 0]`

### 练习 2 参考答案

```go
words := make([]string, 3)
words[0] = "Go"
words[1] = "is"
words[2] = "fun"

fmt.Println(words[1])
```

说明：

- 下标从 `0` 开始
- 所以第二个元素是 `words[1]`

### 练习 3 参考答案

```go
var nums []int
nums = append(nums, 10)
nums = append(nums, 20)
nums = append(nums, 30)

fmt.Println(nums)
```

也可以写成：

```go
var nums []int
nums = append(nums, 10, 20, 30)
fmt.Println(nums)
```

说明：

- `append` 会返回新的 `slice`
- 所以一定要用变量接收

### 练习 4 参考答案

```go
nums := []int{1, 2, 3, 4, 5, 6}

a := nums[1:4]
b := nums[:3]
c := nums[3:]

fmt.Println(a) // [2 3 4]
fmt.Println(b) // [1 2 3]
fmt.Println(c) // [4 5 6]
```

说明：

- `nums[1:4]` 取到的是下标 `1`、`2`、`3`
- `nums[:3]` 表示从开头到下标 `2`
- `nums[3:]` 表示从下标 `3` 到结尾

### 练习 5 参考答案

```go
src := []int{1, 2, 3}

dst := make([]int, len(src))
copy(dst, src)

dst[0] = 100

fmt.Println("src:", src)
fmt.Println("dst:", dst)
```

说明：

- `copy(dst, src)` 会把元素复制到新 `slice`
- 修改 `dst` 时，`src` 不会受影响

### 练习 6 参考答案

```go
nums := []int{3, 5, 7, 9}
sum := 0

for _, v := range nums {
	sum += v
}

fmt.Println(sum)
```

说明：

- `range` 可以拿到每个元素的值
- 这里不需要下标，所以用 `_` 忽略

### 练习 7 参考答案

```go
nums := []int{1, 2, 3, 4, 5, 6}
var result []int

for _, v := range nums {
	if v%2 == 0 {
		result = append(result, v)
	}
}

fmt.Println(result)
```

说明：

- `v%2 == 0` 表示偶数
- 满足条件时追加到结果 `slice`

### 练习 8 参考答案

```go
nums := []int{10, 20, 30, 40, 50}
part := nums[1:4]

part[0] = 100

fmt.Println("nums:", nums)
fmt.Println("part:", part)
```

输出通常是：

```go
nums: [10 100 30 40 50]
part: [100 30 40]
```

说明：

- `part := nums[1:4]` 取的是 `nums[1]` 到 `nums[3]`
- 所以 `part[0]` 实际对应的是 `nums[1]`
- 这说明子 `slice` 和原 `slice` 可能共享底层数组

### 练习 9 参考答案

```go
twoD := make([][]int, 3)

for i := 0; i < 3; i++ {
	twoD[i] = make([]int, i+1)
	for j := 0; j < len(twoD[i]); j++ {
		twoD[i][j] = i + j
	}
}

fmt.Println(twoD)
```

一种可能的输出是：

```go
[[0] [1 2] [2 3 4]]
```

说明：

- 外层是 `[][]int`
- 每一行可以单独 `make`
- 所以每一行长度可以不同

### 练习 10 参考答案

一种容易理解的写法是：

```go
nums := []int{10, 20, 30, 40, 50}

result := append([]int{}, nums[:2]...)
result = append(result, nums[3:]...)

fmt.Println(result)
```

输出是：

```go
[10 20 40 50]
```

说明：

- `nums[:2]` 是前半段，即 `[10 20]`
- `nums[3:]` 是后半段，即 `[40 50]`
- 把两段拼起来，就相当于删除了下标为 `2` 的元素

还有一种更常见的写法：

```go
nums := []int{10, 20, 30, 40, 50}
nums = append(nums[:2], nums[3:]...)
fmt.Println(nums)
```

这版更简洁，但它可能复用原来的底层数组。入门阶段先理解第一种写法会更直观。

## 11. 你学完后至少要真正掌握什么

如果你读完这份教程，建议至少确认自己已经会下面这些内容：

- 能自己创建 `slice`
- 能用下标读写元素
- 能使用 `append`
- 能使用切片表达式截取区间
- 知道 `copy` 是干什么的
- 知道 `slice` 和数组的核心区别
- 知道 `append` 要接收返回值
- 知道子 `slice` 可能和原数据共享底层内容

如果这些点都已经清楚，你对 `slice` 的入门就算比较扎实了。
